# 滑码键盘 · Swipe / Code

独立 Android 程序员滑动输入法，附试打、自定义与手感设置。本项目不依赖 Termux 源码，也不会修改 Termux 的构建配置。

当前版本为 **0.5.0**，已加入系统输入法和 🌐 切换按钮。顶部为 Esc、Shift、Ctrl、Alt、Tab、Del；全部37个键的轻点及四个方向均可自定义。字母键默认只保留字符和符号，已移除C/V/B/N等上的重复快捷键与导航预设。保留Android 16启动修复。

## 安装与试用

将 `SwipeCode-0.5.0.apk` 传到 Honor 400，用手机文件管理器打开并覆盖安装。应用名称是「滑码键盘」。

1. 打开应用的「启用」页面，点击「打开输入法设置」，在手机设置中启用「滑码键盘 · SwipeCode」。
2. 返回应用，点击「选择输入法」，选中滑码键盘。原有系统输入法可以保持启用，无需卸载或关闭。
3. 点击启用页测试框，或切到其他应用的输入框开始使用。
4. 键盘工具栏的「🌐 输入法」打开系统选择器，可切回原来的中文/系统输入法。「定制」打开配置，「⌄ 收起」隐藏键盘。

工具栏「终端」在Termux和原始按键输入框中默认开启，也可手动切换；每次进入新输入框时重新自动判断。终端模式中Ctrl+C等组合直接送到应用，普通编辑框中Ctrl+A/C/V/X/Z/Y走编辑操作。不同终端、浏览器和编辑器对快捷键的支持仍需实际验证。没有自动切换或关闭其他输入法。

## 输入与自定义

1. **试打**：轻点输入字母；向键帽上标注的符号方向滑动，松手输入。顶部显示放大的当前候选。滑回中心恢复字母；松手时处于空方向或键盘外则不输入。
2. **修饰键**：Shift、Ctrl、Alt轻点后亮起，可叠加，输入下一个字符后自动释放；滑动符号、空格、Tab、回车也会释放。空方向或取消触摸不会释放。Ctrl、Alt再点一次取消；Shift连续双击锁定大写，再点一次解除。上下两个Shift共享状态。符号映射不随大小写变化。
3. **退格**：轻点删除选区或光标前一个 Unicode 字符；按住400毫秒后连续删除。支持空格和回车。
4. **自定义**：点击预览中的任意键，包括顶部Esc/Shift/Ctrl/Alt/Tab/Del，以及底部退格、空格、回车、定制键。每键可修改轻点和四个方向。直接填写文字，或点击「字符 / 按键 / 功能」，选择按键组合，或指定Shift/Ctrl/Alt保持与打开自定义页面。文字最多64个Unicode码点，也可清空。点击「将此键四个方向设为↑↓←→」可将任意键变成方向键，轻点绑定保持原样。所有修改最后点击主窗口「保存」才生效；取消不修改。恢复此键会恢复其全部五个绑定。
5. **手感**：键高44～72dp、触发距离8～24dp，以及触感反馈开关。默认56dp、12dp、开启反馈；反馈遵循手机系统设置。

Tab在普通编辑框插入制表符，在终端发送Tab；在Alt上向四个方向滑动移动光标，保持滑动400毫秒后连续移动，松手停止。Shift+箭头选择文字，Ctrl+左右箭头按单词移动；箭头和退格保留已点亮的修饰键。其他按键绑定会释放一次性修饰键。顶部Del向后删除，底部退格向前删除。普通编辑框中的Ctrl+A/C/V/X/Z/Y分别对应全选、复制、粘贴、剪切、撤销、重做，Ctrl+Shift+Z也可重做。系统输入法的回车键按当前输入框显示/执行搜索、发送、完成等动作；Shift+Enter保留换行，终端发送原生Enter。

Esc、Ctrl+L、Ctrl+P和F1–F12等发送原生按键事件，效果取决于接收应用。Ctrl+L在支持的终端中通常清屏；当前试打区是文本编辑框，不模拟终端清屏。键盘上方显示已发送的按键，按下预览显示完整组合名称。键帽用 ^ 表示Ctrl、⌥表示Alt、⇧表示Shift、◆表示Meta。

试打区支持选择文字、移动光标、复制、清空和选区替换。切换页面不会丢失试打文字。配置保存在本机，应用重启后保留；试打文字保留于当前会话和界面重建，不承诺进程退出后保留。

空格也是合法文本绑定，以 `␠` 显示；换行和制表等控制字符请使用Enter、Tab按键绑定。

|---|---|---|---|---|---|

| K3 | Ctrl保持 | Ctrl+A | Ctrl+L | Ctrl+P | Ctrl+C |
| K4 | Alt保持 | ↑ | ↓ | ← | → |

## 离线构建

在此独立项目的根目录运行以下命令；与Termux仓库无依赖关系。

使用现有工具：JDK 21、Gradle 8.11.1、Android SDK / Build Tools 35.0.0，以及本地已缓存的 **AGP 8.7.3**。原计划的8.9.2未缓存，因此选用已安装版本，未下载任何新工具或依赖。最低 Android 8.0（API26），目标 API35，无本地CPU架构依赖。

```bash
cd Keyboard-for-programmers
bash tools/build-offline.sh
```

构建脚本只以 `--offline` 运行，禁止SDK自动下载，使用SDK里已有的AAPT2。如本机组件或缓存缺失，应停止并先询问用户，不自行安装。

- 应用：`app/build/outputs/apk/debug/app-debug.apk`
- 设备测试包：`app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`
- 应用包名：`com.nurdun.swipecode`
- 调试包已签名，适合此次手机试用；不是应用商店发布包。

## 结构与下一阶段

- `core/`：纯Java布局、版本化配置编解码、独立触点手势、修饰键状态与操作路由、文本编辑逻辑。
- `SwipeKeyboardView`：键帽绘制、候选预览、多触点与长按；只通过 `KeyboardOutput` 发出编辑操作。
- `EditTextOutput`：试打区的文本编辑适配器。
- `SwipeCodeImeService`：系统输入法宿主与输入法切换、终端模式、生命周期处理。
- `InputConnectionOutput`：跨应用文字、Unicode删除、编辑操作、原生组合键与回车动作适配。
- `KeyboardStore`：本地私有配置；`MainActivity`：试打、自定义与手感界面。

系统输入法与试打区复用同一键盘和本地配置。切换输入框或隐藏键盘时清除修饰键、候选及重复计时器；不保存其他应用的输入文本，不加入自动纠错、联想或联网权限。服务由Android的BIND_INPUT_METHOD权限保护，此权限是服务调用方限制，不是应用申请的运行时权限。
